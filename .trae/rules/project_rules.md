# 项目全局规则（Trae，默认自动遵守，除非当次任务明确要求覆盖）

> 本文件适用于 `english-listening-video` 项目。每次任务默认遵守以下规则，无需用户重复交代。

## 一、工作目录与 Git 规范

1. 所有代码修改、运行与文件管理必须在当前目录 `english-listening-video` 下进行，**严禁新建同名嵌套目录**。
2. 保留并复用现有**火山引擎 TTS 鉴权与调用配置**，不破坏已有配置。
3. 每次完成代码、模板、配置或规则改动并验证通过后，必须主动执行 `git status`、`git add`、`git commit` 并汇报 commit hash 与改动摘要。
4. **严禁提交** `.env`、密钥、虚拟环境及 `output/` 下的视频/音频产物。

## 二、对比图生成规范（生图默认风格）

1. 画幅为 `16:9` 横屏，整体画布为**纯白色（`#FFFFFF`）**。
2. 版面为**两张独立的圆角方形卡片**左右并排，中间留出清晰的**纯白色间距（约占总宽 8%～10%）**，**严禁在中间画竖向分割线**。
3. 每张卡片内部必须是**铺满卡片的彩色卡通教材插画场景**（线条清晰、暖柔和色调），使圆角边缘与纯白间距对比鲜明。
4. 左卡片左上角配**蓝底白边粗体白字圆形“A”标**，右卡片左上角配同等样式的**圆形“B”标**；除题干必要元素（如价格标签）外，画面不出现多余文字。
5. 生成的图片保存到 `input/` 目录；若文生图工具产出 `.jpg`，须无损转换为真正的 `.png` 再入库。

## 三、视频画面规范（极简大图直出）

1. 输出标准横屏 `1920x1080` `.mp4` 文件（必须完整嵌入音轨，不可只保留 `.webm`）。
2. 画布纯白背景（`#FFFFFF`），与对比图无缝融合。
3. **仅保留两个视觉元素**：顶部居中黑色粗体标题 `英语听力：哪张图是对的？` + 中间最大化清晰展示的 A/B 对比图。
4. **严禁出现以下元素**：底部提示文字（如“听录音，选择正确的答案”）、中文翻译、考点解析、正确答案高亮、英文字幕、学段角标、进度条或花哨背景框。
5. 渲染前自动裁切原图外围多余的纯白空白边界（仅保留极小安全边距），确保 A/B 卡片足够大、留白克制均衡。

## 四、音频与出题规范

1. 不调用外部视觉识图大模型 API，直接接收外部传入的英文听力稿，**严禁回退使用** `"Listen and choose a picture."` 等占位文本。
2. 使用火山引擎 TTS 按对应学段（默认 `primary_g4`）清晰自然朗读，正文时长控制在 10 秒左右（约 8～12 秒）。
3. 默认在每条听力正文前自动拼接开场提示音 `assets/sfx/intro_ding.wav` + `0.5` 秒静音停顿（拼接前必须统一采样率、声道与编码格式，确保不变调、无爆音、结尾不截断）。
